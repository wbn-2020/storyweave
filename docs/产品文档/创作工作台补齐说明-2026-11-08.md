# 创作工作台补齐说明

编写日期：2026-11-08。对应[功能与代码复审](../审查报告/小说创作工作台功能与代码复审-2026-11-08.md)中的 C01–C02、F01–F12 和 R01–R04。用户已确认本轮同时补齐创作主流程与扩展功能。

本轮交付的是源码实现及静态复核结果，尚未运行客户端、测试、类型检查、构建或打包。界面和数据迁移需要在明确授权的验证环境验收；不能把旧批次的运行记录当作本轮证据。

## 创作入口与使用流程

| 范围 | 入口与当前行为 |
| --- | --- |
| C01 服务退出后关闭 | 主进程仍先确认模型结果和界面草稿；服务进程确已退出时不再要求向它发送关闭命令。正在运行但无响应不视为已退出。 |
| C02 返回写作 | 按本地书库记录最后打开的作品、章节、段落选区和滚动位置。首页继续写作与书架打开共用位置；明确点击某章仍按该章打开。偏好存储失败时保留本次会话位置。 |
| F01 规划 | “规划与审稿”提供跨章大纲、计划与实际字符数、章节目标与视角；场景卡记录目标、冲突、结束变化、人物、地点、故事时间、情节线、状态和排序。卡片可以先于正文建立，关联正文时固定章修订与段落。改卡片顺序不会移动正文。AI 规划可经作者选择带入卡片。 |
| F02 创作约定 | “创作约定”保存故事前提、文风、叙述人称、时态和规则。作者视角的 AI 创作上下文固定这些字段及作品题材、简介，发送前可检查。受限读者／人物视角不自动发送全书约定与简介。 |
| F03 实体消歧 | AI 知识审阅可选择新建、关联已有条目并追加来源、明确修订已有字段、忽略。关联使用稳定条目 ID 和作者读过的修订；同名不自动合并。普通 AI 和逐章整理共用该审阅行为。 |
| F04 审稿 | AI 协作可选择审稿；作者将候选登记为问题，记录类型、理由、证据、建议和固定原稿。状态为待处理、待复核、已解决、有意安排、误报。明确确认后，可把替换正文应用到连续段落并保存新版本；应用只转为待复核。基线变化显示过期，须重新定位复核后才能标为解决。首次记录的定位、证据、理由仍可独立展开，并按固定版本查看原文。 |
| F05 修订 | 版本历史可对照当前稿与选中历史／定稿，查看段落新增、删除、修改、移动并选择局部恢复；恢复生成带来源的新修订。AI 建议可逐段选择组成待采用文本，再经原有采用门禁写入。 |
| F06 伏笔 | 计划回收支持未知、未来卷／章／场景或文字范围；没有正文也可先规划。实际回收继续要求可核对的固定正文出处。旧版已定位计划保持可读。 |
| F07 边写边查 | 正文“伴随资料”可固定显示目标、人物、地点、伏笔与知识；查看资料不打开模态编辑器。来源先展示固定历史稿，另行核对后可跳到当前稿，并返回原写作位置。编辑资料仍使用原有保存门禁。 |
| F08 历史认知 | 故事记录支持形成、修正、推翻、隐瞒、遗忘及有效截止。变化追加为新状态；已保存的状态内容不被后来的真相覆盖。人物上下文按明确故事排序筛选，排除到期、替代、遗忘和推翻状态。普通知识须显式选择人物和故事时间才能转换。 |
| F09 新手引导 | 新建作品可直接写第一章、从主角／愿望／阻碍开始，或转入导入。种子可留空；前提和第一章在同一建书事务中建立。首页根据空目录、缺少目标或待审章节提供下一步入口。 |
| F10 目标与记录 | 日／周目标支持保存稿新增、净增、分钟和改稿章次；新增、删除、净增分别显示。手写、AI、导入、恢复分栏记录。时段和完成改稿由作者手工登记，未实现自动计时。 |
| F11 全局收集 | “全局灵感收件箱”独立于单部作品。参考作品、场景观察、摘录、手法分析、方法卡通过父子链组织，保存出处与标签，可关联作品、归档或明确复制到作品笔记。原件与历史保留，不抓取外部小说，不自动转成设定。 |
| F12 交付 | 导出先选择章节并生成清单，逐章说明未勾选、缺少定稿或正文不可用，支持固定稿预览。确认后输出 TXT、Markdown 或 EPUB，以及独立 manifest。清单固定作品与章节修订，版本变化须重新预览；不自动投稿。 |

## 恢复与数据范围

| 范围 | 当前行为 |
| --- | --- |
| R01 未完成恢复 | 预览区分新目标、可续办、未完成冲突和已有作品冲突。续办重新核对包身份、清单和已复制内容；不覆盖残件或删除原目录。不能续办的情况明确提示保留目录并选择其他书库目标。 |
| R02 检查点容量 | 可查看当前代的文件数和容量，接近上限提示；作者可建立新一代继续保护，旧代不搬移、不清空，仍可选择预览恢复。 |
| R03 模型结果 | 请求模型前检查结果目录可写性和磁盘余量，日志接近容量阈值时自动建立新卷，旧卷保留。接收完的模型终态先写入书库待提交文件，再提交本地服务。重开书库后核对原候选和上下文，补存本地结果，不重新请求模型。日志仅保存结果及必要身份，不保存会话密钥。 |
| R04 包校验 | 在文件摘要与数据库结构之外，恢复预览核对知识／故事／AI／笔记及新增创作工具的业务可读性和固定来源。单书包只含该书数据库与登记的导入原件。 |

单书恢复包不包含 `studio.sqlite`、`inspiration.sqlite`、书库草稿检查点、待提交模型结果目录和升级备份。全局收集内容若需随作品包交付，可先明确复制到作品笔记；这不会移走全局原件。升级前备份仍只是数据库备份，不能替代整份书库留存。

## 数据与体验边界

- 新建与导入作品使用 book v13；旧作品继续读取，启用新工具须在面板明确备份升级。未执行对用户真实作品库的迁移。
- 场景、审稿各最多 2,000 条，目标最多 100 条；单条序列化内容上限 256 KiB，完整工作台快照 16 MiB，关联的不同正文修订合计 64 MiB。提交前使用同一读取预算核对，超限拒绝本次修改，不截断已有资料。
- 写作统计默认显示最近一年。字符口径为非空白 Unicode 码点，含标点。纯分段、合并和不改文字的整段移动不算新产出；旧文字按序完整保留时只计净新增。混合改写仍为估算，多处编辑可能多计中间文字，跨段删写相同文字也可能被视为复用而少计；净增反映保存前后的字符差，不表示敲键次数。旧统计不回算。
- 已有旧认知的编辑历史缺少明确故事时点，不能自动还原过去的知情状态；新的显式状态链提供可查询的有效区间。未记录的信息保持未知，人物模式不承诺逐句防剧透。
- EPUB 使用现有正文结构和原生 ZIP 写入，支持标题、分场、加粗、斜体；未在阅读器中做运行兼容性验收。导出预览有效期 30 分钟，成品有容量上限。
- 返回位置是界面偏好，正文和修订保存在作品数据库；位置偏好不替代草稿保护或备份。
- 模型结果发送前预检不能保证生成期间磁盘余量不变。持久待提交记录保护的是已接收并完整落盘的终态；生成途中不足检查点阈值的尾部，在异常退出时仍可能无法恢复。

验证证据和后续授权验证范围继续维护于[开发进度](../开发进度/开发进度-2026-11-06.md)。
