## 一、 为什么要重构前端 UI？

原有界面存在三大核心体验缺陷：
1. **政务后台式的冰冷视觉**：大面积 `#edf0f5` 冷灰配 `#0865d1` 高饱和工业亮蓝，缺乏小说创作所需的文学温度与沉浸式书房氛围。
2. **“阴阳脸”主题精神分裂**：全局 `:root` 默认是深黑底色（`#10151b`），而首页与部分弹窗局部覆盖为纯白亮蓝，导致用户在白底首页点击「故事设定」、「关系星海」、「故事时间线」、「AI 协作」时瞬间弹出乌黑背景的模态框。
3. **反人类的“弹窗地狱（Modal Hell）”**：主画布仅有 3 个视图，而多达 26 个核心功能（包括故事设定、关系星海、时间线、规划与审稿、创作日历、甚至 AI 协作）全部以遮罩 `<dialog>` 弹窗形式糊在屏幕上，且打开弹窗时强制锁死底层正文编辑器，无法边看正文边用 AI 副驾驶。

## 二、 本次重构的核心设计方案（Mirroric + StarWriter V2.4.8 全流程小说工作台）

彻底推翻此前容易让页面空洞、难辨识的设计，深度吸纳 **小红书 StarWriter V2.4.8**、**Mirroric Agent 写作空间**、**豆豆写作工作台** 以及 **小狼 8 大神级 Skill** 的工业级功能与界面设计：

### 1. 228px 极简现代侧边栏（左侧图标 + 清晰中文标签，拒绝过窄）
- **左侧舒适导航栏（[App.tsx](../../src/renderer/App.tsx) / [App.module.css](../../src/renderer/App.module.css)）**：
  - 顶部设立 `创作空间 网游之星河传说 ⌵` 快捷卡片，直观显示当前作品名、章节数与总字数；
  - 9 个主入口（`创作概览`、`章节正文`、`故事大纲`、`人物角色卡`、`关系星海`、`故事时间线`、`拆书与技能库 (8 Skill)`、`素材与便笺`、`作品书架`），配标准 16px 图标与 13px 清晰中文标签；
  - 底部集成「StarWriter 多主题快速胶囊换色器（星河暖玉 / 宣纸朱砂 / 夜墨星海 / 莓果奶霜 / 松烟青黛）」与「一键明暗模式切换（☀️ 日间 / 🌙 夜间）」。

### 2. StarWriter 经典首页（继续上次创作 + 今日目标 + 横向封面作品库）
- **继续上次创作主卡（[WelcomeWorkspace.tsx](../../src/renderer/components/WelcomeWorkspace.tsx)）**：
  - 左侧展示封面，右侧展示正在编辑的章节名、字数进度条、继续写作主按钮与大纲直达；
- **今日目标与创作沉淀（右 1/3）**：
  - 展示今日码字字数、目标进度条与作品库数据沉淀（连载作品 / 已建章节 / 已定稿章）；
- **标志性「我的作品」横幅卡片画廊**：
  - 带有大书名暗纹水印的横向作品卡片，支持搜索、一键打开、新建插槽，即使多部小说也能清晰管理。

### 3. StarWriter 角色卡与设定集全面改版
- **人物角色卡（[KnowledgePanel.tsx](../../src/renderer/components/KnowledgePanel.tsx) / [KnowledgePanel.module.css](../../src/renderer/components/KnowledgePanel.module.css)）**：
  - 列表采用**姓氏彩色圆章头像**，并高亮「主角 / 配角 / 反派」定位标签；
  - 详情页内置**六维属性能力雷达图（执行力、执念度、心性壁垒、辨识度、言辞张力、战力技能）**与进度柱状图；
  - 内置**去 AI 味角色起名器**：避开萧/叶/林/苏/顾等烂大街姓氏，按东方仙侠、科幻异能、都市悬疑题材一键头脑风暴并直接建卡；
  - 内置 **9 种世界观流派模型卡片（修仙、末日、高武、克苏鲁、废土等）**，开箱即用一键套用。

### 4. 审稿与规划进阶：朱雀 AI 味检测 + 多维读者模拟 + 故事建筑师
- **朱雀 AI 味检测（[WorkbenchPanel.tsx](../../src/renderer/components/WorkbenchPanel.tsx)）**：
  - 七维特征扫描 AI 痕迹，标出“比喻太工整生硬”、“面具化神态动作（如嘴角勾起弧度、眼中精芒）”、“情绪过于正确平板”，提供原句与建议改写对比；
- **多维读者模拟**：
  - 模拟「小白读者（看爽文/重节奏）」、「老书虫（盯逻辑漏洞/设定冲突）」、「起点资深编辑（盯商业买点/黄金三章追读留存）」三重视角章评；
- **故事建筑师指令打包**：
  - 从想法箱勾选灵感脑洞，一键打包为高质量长篇架构 Prompt，生成故事约定与黄金场景节拍。
