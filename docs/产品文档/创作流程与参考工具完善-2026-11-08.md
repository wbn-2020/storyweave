# 创作流程与参考工具完善

编写日期：2026-11-08。本文接续[创作工作台补齐说明](创作工作台补齐说明-2026-11-08.md)，记录参考资料对照后继续实施的四组功能。状态为源码实现与静态检查；运行验收及未验证事项见[开发进度](../开发进度/开发进度-2026-11-06.md)。

## 从计划和资料进入写作

AI 创作协作新增“场景、资料与写作方法”。作者可以选择本章或未归章的场景、本书笔记、全局资料，以及六种内置方法：场景描写、单感官段落、人物动机、冲突递增、伏笔回收、对白与潜台词。最多选八项，并填写本次使用要求。

保存发送预览时读取选中资料的完整内容与固定版本。发送和采用时再次核对，已改变、归档或正文定位过期的资料要求重新选择；不会用最新内容悄悄替换旧预览。计划、参考材料和方法分别标记，不自动变成本书设定或已经发生的事实。受限人物／读者视角和章节整理不接受这些自由资料。

## 参考文本、拆书与方法库

1. 在“全局灵感收件箱”选择 UTF-8 TXT 或 Markdown 文件。单文件最多 1 MiB，预览分段后由作者确认整批保存；原文和出处留在当前书库的全局资料库。
2. 在任一作品章节的 AI 创作协作中选择“拆书”，选择参考原文，填写分析要求并核对发送预览。任务只发送选定资料与本次要求，不附加本章正文、作品简介或创作约定。
3. 返回结果按场景观察、摘录、手法分析、方法卡逐项审阅。每项引文须逐字存在于对应固定原文中；作者可以编辑分析与标题，明确选择入库项。
4. 入库保留原文 ID、来源版本、候选记录和引文。全局方法可以在下一次创作中直接选用，也可通过已有入口复制到本书笔记。

导入采用固定条目标识和整批事务，失败不留下半批条目。拆书候选允许部分采用；同一条目跨窗口重复入库会提示查看已有资料。引用超过容量、原文版本变化或模型输出格式不符时保留内容并提示处理，不截断证据或自动修补模型结果。

拆书任务目前借用当前章节保存模型候选与连接，尚无脱离作品的独立任务中心。全局资料库不包含在单书恢复包中；保存整座书库时应包含该独立数据库。

## 人物、关系与时序

| 入口 | 本轮补充 | 使用边界 |
| --- | --- | --- |
| 故事设定 → 人物 | 动机、愿望、弱点、外貌、说话风格、背景、成长阶段、技能限制 | 八项均可选，每项最多 4,000 字符；旧数据和省略档案的修订保留已有档案，明确清空才移除当前值 |
| 关系星海 → 关系画布 | 二维布局、关系名称、鼠标拖动及键盘移动；选两个实体后明确建立关系 | 关系是本书正式记录；画布坐标是本机布局偏好，不包含于单书恢复包 |
| 故事时间线 | 事件、人物认知、关系、伏笔四类可选轨道 | 合并排序与分页；关系起止、伏笔里程碑独立显示，使用稳定来源标识返回记录 |

故事时点与读者披露位置继续独立表达。未填写的时间不按章节顺序猜测，认知记录不自动当作客观事实。

## 写作安排、模型复用与交付

| 入口 | 本轮补充 |
| --- | --- |
| 创作日历 | 月历、计划／截止／发布／灵感安排、目标字数、备注与完成标记；显示逐日写作记录 |
| AI 创作协作 → 任务预设与累计用量 | 每书保存规划、续写、改写、审稿、拆书要求，可绑定模型连接并设置首选项；手动填入后仍需确认发送 |
| 封面与人物立绘 | 导入本地 PNG、JPEG、WebP；封面或绑定已有本书人物的立绘；最新记录作为当前图，保留旧图片 |
| 首页与书架 | 显示已保存的当前封面；未设置或无法读取时保留生成封面 |
| 导出 → DOCX | 固定章节清单与预览、前言、后记、作者信息、基础投稿排版；支持 A4、双倍行距、首行缩进和页码 |

完成日程不增加实际写作字数；“发布”是作者登记的安排，没有连接发布平台。累计用量汇总接口已返回的输入／输出 tokens，缺失字段和未知运行单列，不计算未经确认的费用。

图片每张最多 2 MiB，每书最多 100 张、原图合计 64 MiB，旧图计入上限。图片保存在本书数据库中并随单书恢复包保存；当前文稿导出不嵌入这些封面或立绘。DOCX 仍需在 Word／WPS 中做实际打开和排版验收。

## 数据升级与保存保护

新建作品格式为 v14。旧作品通过明确的“备份并升级”入口启用新增表，读取不会隐式迁移。人物档案、日历、预设、图片和对应历史进入本书数据库，恢复包校验覆盖这些新增数据；目录库和全局资料库版本保持原值。

导入、拆书审阅、日历、预设、关系创建和图片表单均参与离开保护。请求结果未知时保留提交内容，只核对原请求；无法查询时提供内容留存和恢复入口。已确认保存但目录同步失败时可以重试同步。

## 后续范围

角色聊天、移动端与跨设备同步、成就与运营发布工具仍在后续范围。当前没有接入图像生成服务，也没有自动把参考作品扩展为未读取的全书分析。后续先在获准环境中验收本轮保存、升级、恢复和模型调用流程，再据实际使用反馈安排这些能力。
