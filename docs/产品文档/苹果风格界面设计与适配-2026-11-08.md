# 苹果风格界面设计与适配

编写及更新日期：2026-11-08（Asia/Shanghai）。本次针对正式 Electron renderer 的首页、书架、写作区、显示偏好和基础编辑弹窗进行优化，包含同日的内容层级深化。实现入口为 `src/renderer/App.tsx`，验证证据见[开发进度](../开发进度/开发进度-2026-11-06.md)。

## 使用场景与设计取舍

作者在电脑上持续写作，需要随时回到最近章节、查看作品信息，并在窄窗口中继续使用同一套功能。界面采用浅灰导航、白色内容、蓝色主操作和开放列表。作品封面、书名、简介和最近章节构成首页核心，统计与故事工具处于次要层级。正文纸色继续由显示偏好决定。

苹果风格主要体现在内容层级、导航结构和控件状态。磨砂限于侧栏与工具栏，正文及信息卡保持实色；不制作假系统窗口按钮，也不引入苹果专有字体或图标文件。

## 调研资料与落地

本轮参考 Apple Human Interface Guidelines，并进一步读取官方 Materials、Layout、Sidebars、Tab bars 正文，对照 Apple Books 与 Notes 官方使用指南中的应用截图。以下为官方来源与本项目采用的规则；像素、断点和配色是本项目的实现取值。

| 官方专题 | 来源 | 本项目采用的规则 |
| --- | --- | --- |
| Materials | `https://developer.apple.com/design/human-interface-guidelines/materials` | 导航与内容层分开；半透明用于操作层，信息主体使用稳定实色背景 |
| Sidebars | `https://developer.apple.com/design/human-interface-guidelines/sidebars` | 侧栏承载稳定的功能层级，支持收起，窄空间采用替代导航 |
| Toolbars | `https://developer.apple.com/design/human-interface-guidelines/toolbars` | 主要操作集中，相关操作分组；文字与统一线图标一起提供含义 |
| Layout | `https://developer.apple.com/design/human-interface-guidelines/layout` | 随可用空间改变结构，保持主要任务入口和内容可达 |
| Typography | `https://developer.apple.com/design/human-interface-guidelines/typography` | UI 使用系统无衬线字体，标题、正文、辅助说明建立稳定层级 |
| Accessibility | `https://developer.apple.com/design/human-interface-guidelines/accessibility` | 保持文字对比、焦点可见及足够的操作面积，尊重减少动态和透明度偏好 |
| Tab bars | `https://developer.apple.com/design/human-interface-guidelines/tab-bars` | 稳定的主要目的地、图标配文字、浮动导航与内容保持层级；常用功能保持直达 |
| Books User Guide for Mac | `https://support.apple.com/guide/books/welcome/mac` | 参考作品封面、白色内容画布与开放书架布局；封面用项目已有组件绘制 |
| Notes User Guide for Mac | `https://support.apple.com/guide/notes/welcome/mac` | 参考正文优先、紧凑工具组，以及电脑／平板／手机间的信息层级 |

官方文档将 Liquid Glass 限定为导航与控件层，并建议谨慎使用自定义玻璃效果。布局文档强调按重要性排序、对齐、利用留白与分隔线分组，以及渐进展示。Tab bars 文档提醒不要过度依赖“更多”隐藏主要功能；本项目的工作台、写作、书架直接显示，其他工具集中到更多导航。涉及保存和未确认回执时，导航仍服从项目既有的数据保护规则。

本机参考截图保存为 `out/Apple-Books-官方参考-2026-11-08.png` 和 `out/Apple-Notes-官方参考-2026-11-08.png`，仅用于设计对照；正式界面未引入这些截图或其中的书籍封面。

Apple 对 iOS 默认控件尺寸的建议以 pt 表达。本项目使用 CSS 像素：窄屏首页可用按钮的检查目标为至少 44×44 CSS px，不能据此宣称已完成原生设备的触控验收。

## 视觉和信息结构

- 桌面外层使用 `#edf0f5`，首页与书架使用白色内容画布，次要分组使用 `#f3f5f8` 等轻灰色。UI 文字 `#1d1d1f`、辅助文字 `#636366`、主操作 `#0865d1`。系统字体依次使用当前操作系统可用字体，无额外字体下载。
- 桌面主体使用 16px 圆角，故事工具使用 12px 圆角，主要操作采用胶囊形状；章节和最近作品采用开放列表及细分隔线，避免多层边框争夺注意力。
- 首页顺序为继续创作、紧凑统计、最近章节、故事工具；桌面右侧显示最近作品与作品库操作。封面复用书架 `BookCover`，内容来自真实书名、类型和简介；未选库时使用明确的空手稿占位。
- 已有作品时以继续写作为主要操作，新建与导入使用次要样式；空库突出新建。顶部页面切换在桌面侧栏收起时显示；正常侧栏状态下保留一套主要页面导航。
- 书架统一筛选、搜索、作品列表与空状态，强调封面和书名。正文工具条分为格式和编辑两组，以细分隔替代各组外框；纸面保留用户字体、行距和纸色设置。
- 显示偏好、新建与资料编辑等基础弹窗采用浅色表单。复杂业务面板仍有既有深色样式，未在本轮宣称全应用主题切换完成。

## 窗口宽度适配

| 可用宽度 | 导航与布局 |
| --- | --- |
| 大于 1050px | 完整侧栏，可手动收起；收起后显示顶部分段导航；正文按空间保留目录与本章记录 |
| 701–1050px | 侧栏收紧，工作台区域重排；正文保留目录，优先给正文留空间 |
| 不超过 700px | 浮动胶囊导航显示工作台、写作、书架、更多；写作目录按需展开，无当前章时自动展开；首页统计压成一行 |

窄屏输入框使用 16px 字号；底部导航与首页、书架、正文的预留空间同时计算安全区。专注模式隐藏导航与目录，Esc 可退出。减少透明度或提高对比度偏好下，导航改用实色背景。

## 交互保护

- 页面切换沿用原有保存、输入法、未确认回执和恢复门禁；同章往返工作台保留编辑器及撤销记录。
- “更多”到目标弹窗先关闭导航，再打开目标；保存等待期间不能重新打开导航，恢复入口在未确认回执状态下仍保留。
- “更多”忙碌时使用 `aria-disabled` 配合函数门禁，保持弹窗关闭后的返回焦点。导航打开时不允许背景专注快捷键改变页面。
- 浅色输入框和选中预览采用足够的选择器优先级，避免旧深色表单样式覆盖；窄屏字号规则同步匹配。
