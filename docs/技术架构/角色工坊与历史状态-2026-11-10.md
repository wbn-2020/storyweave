# 角色工坊与历史状态

更新：2026-11-10。对应[AI 原生重构方案](../产品文档/小说工作台AI原生重构方案-2026-11-09.md)的 M3。当前为源码完成待运行，检查证据及运行验收范围见[开发进度](../开发进度/开发进度-2026-11-06.md)。

## 入口与任务

“角色与世界”进入工坊，手工设定、关系画布与人物立绘保留独立入口。人物详情可以进入补全、正文提炼或试戏。工坊复用本书现有模型连接、准备预览、明确发送、取消、中断和主进程终态补存，不增加另一套网络会话。

| 任务 | 输入与结果 | 入库方式 |
| --- | --- | --- |
| 起名 | 一至四组，每组三个名字；固定本书已有名字、别名及作者避用名称 | 复制名字，不直接建卡 |
| 角色班底 | 一至四张人物卡，八维档案及可选六维能力 | 逐卡选择、编辑后创建人物设定 |
| 补全档案 | 指定一名已采用并复核的人物 | 仅填空白说明、文字档案和能力维度 |
| 正文提炼 | 指定人物及完整参考章，逐字引文 | 仅填空白字段，并登记固定正文来源 |
| 世界锻造 | 一至四张地点、势力、物品、规则、主题等卡片，可明确接续一轮原始世界提案 | 逐卡选择和编辑后采用 |
| 关系推断 | 完整参考章与明确选入的至少两个实体，最多十条关系候选 | 保留端点、候选身份与引文，编辑后创建关系 |
| 角色试戏 | 明确故事时点、手选历史档案字段、当时有效的认知与状态 | 保留任务原文，复制到正文后由作者修改 |

名字意象属于创作解释，不宣称已核验典籍出处。同音避坑由本次要求约束模型；确定性重名检查覆盖既有名字、别名与避用名称，不提供谐音词典或全网重名保证。

## 固定发送边界

契约在 `src/contracts/forge.ts`，固定资料和采纳在 `src/infrastructure/workbench/forge-repository.ts`，历史读取在 `forge-state.ts`。四个命令为 `forge.get`、`forge.prepare`、`forge.run`、`forge.adopt`，均接入契约、请求校验、主进程白名单、服务及 preload。

模型任务使用 `kind=plan`、`purpose=forge`；不可变封装标记 `workflow=forge-v1`，保存要求、范围、所选资料的固定修订与历史快照。准备时与正式发送前均核对作品、知识和章节版本；输入变化后须重新准备。

只有正文提炼和关系推断发送完整参考章。其他任务不发送章稿、章节目标、备注、自动全书创作约定、检索片段、分层摘要或写作资料。试戏连参考章标题、作品标题都不进入消息，仅保留技术身份和版本锚点；作者情境仍可能含人物未知信息，发送前须审阅实际消息。

世界续谈每次只固定明确选中的一轮原始输出，不隐式展开此前对话。该输出是待讨论的构想，不代表已经采用。模型输出为自然语言试戏或严格 JSON 提案；不能把不完整输出当作正式卡片。

## 档案与历史认知

六维能力为力量、敏捷、耐力、感知、谋略、影响力，值为作者确认的 0–100 整数。未知维度省略，不以档案文字长度计算分数；雷达只有六项齐全时才连接面积，其他情况只显示已知点与“未知”。能力内容随知识修订进入历史与记忆投影。

历史读取使用固定知识修订号，旧试戏不会根据当前档案重建未来版本。人物身份只提供名称与固定修订，试戏不自动附加当前简介、别名、成长阶段或其他全知资料。作者须明确选择符合故事时点的档案版本及具体文字字段；当前没有从自由文本自动推导人物历史性格。

认知以既有 `cognition` 状态链为依据，核对同一主体、前态、严格递增时间和唯一后继；有效区间包含形成时点、不含截止时点，并受更早的后继形成时间限制。知道、相信、误解、怀疑和隐瞒分别保留；遗忘、推翻及未采用、非当前、未复核的状态不能作为仍持有的认知发送。

作者独立登记的认知可以没有获知事件；有关联时，事件须是已采用、当前且完成复核的作者设定或正文陈述，并有不晚于认知形成的明确故事排序。关联事件详情、后继内容与未来截止时间不进入试戏消息，也不由同场或关系推断人物知情。

事件状态按人物、属性与显式故事排序筛选，只允许选择时点前最后一项。属性存在未知时间、同一时点多条变化、缺少变化后状态或最后记录未复核时，保持不可用。M2 的发布记忆不自动转成人物心智或带故事时间的事件。

## 关系画布

拖线模式从一个知识实体拖到另一实体，松开后填入关系草稿，作者确认后才保存。键盘可依次聚焦两端并按 Enter，Esc 退出；原有移动和两端选择框继续可用。

关系增加可选 `layer=surface/hidden`，旧记录省略时显示“未标注”，不补写为表面关系。画布可按本页关系层次筛选，输入明确故事排序值或拖动本页已登记时间范围，显示关系有效、失效或未知，并可隐藏已失效关系。有效期不按章节号推导；当前没有章节至故事时点的自动映射。

隐藏关系、读者披露、人物认知、有效故事时间分别保存。关系边不是客观事实或人物已知的证明；模型推断关系采用后仍标记冲突未检查，需要在故事记录中复核。

## 采纳、格式与恢复

新书为 book v17，工作区仍为 studio v3。v16 及更早作品经已有备份升级流程追加工坊表；读取旧书只提示升级，不隐式迁移。旧格式不能写入能力数值或关系层次；v14、v15、v16 恢复各用自身 DDL 基线。

| 表 | 内容 |
| --- | --- |
| `forge_runs` | AI 任务外键、任务类型、规范化请求和固定封装，不可变 |
| `forge_receipts` | 采用内容及结果实体／关系 ID 和修订 ID，不可变 |

一次采用使用同一书库的立即事务，核对固定请求、任务版本、作品与知识版本、候选身份、端点和逐字引文。复用知识／故事仓储写正式修订与来源，每项依照原领域规则推进作品和知识版本；任一项失败则整次回滚。目录缓存只在外层事务结束后更新。

相同采用内容再次提交返回原回执，内容不同则冲突。填空保持原名与已有非空字段，零分也属于已有能力值。所有采用附作者确认说明；正文提炼和关系推断另附一至八处固定段落引文。创建的卡片是作者采用的设定，仍标记冲突未检查。

恢复校验工坊任务与 AI 用途对应、规范请求、固定历史资料、完整章稿、续谈先后顺序、采用终态与回执、结果修订内容以及作者／正文来源。正文锚点始终保留，不以当前稿替换历史引文。

工坊面板提供异常结果的内容留存和恢复入口，记录当前任务输入、人物历史选择、候选编辑与选用范围、已读原始输出、最近一次操作尝试及回执编号。作者手动复制后确认当前记录，才能从面板进入草稿与服务恢复；输入、候选或记录变化会使确认失效。未知采用仍查询原写入回执，不能将进入恢复视为原操作失败。

读取与模型控制的失败保留原请求编号，无编号错误不覆盖已有编号。核对原读取只确认请求是否确定结束，不填回迟到数据、不再次发送模型控制；后续由作者明确读取原提案状态。没有可查编号或回执不可用时，仍可先留存当前内容，再进入主窗口恢复流程。手动记录仅含当前已读内容，未补存的模型终态继续由主进程保护。

## 读取与预算

- 实体选择列出前 200 个，显示总数；最近任务列出 30 个，人物档案列出最近 20 个并显示总数。人物详情入口可直接带入列表外身份。
- 单人物最多读取 200 条相关故事记录；历史快照最多一百万 UTF-8 字节；超限明确拒绝，不截断后继续推断。
- 手选实体最多 20 个，试戏认知与状态各最多 12 项，档案文字字段最多 8 个。
- 起名与班底的全书避名范围最多一千个实体；固定要求和资料封装最多 48,000 个 UTF-16 字符，原始世界续谈来源最多 40,000，采用内容最多 60,000。
- 继续受现有完整消息 80,000 字符及连接上下文预算限制；超限后由作者缩小范围，不自动删减正文。
