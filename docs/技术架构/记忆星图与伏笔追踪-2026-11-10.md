## 星图与来源

记忆星图保留星海、关系画布，并增加章节出场矩阵和伏笔雷达。星海按现有查询分页，每页最多 40 个对象，聚焦页另含中心对象；只绘制本页已登记的直接引用。2026-11-12 对照 V3-15 后使用有界同心环布局，每环最多 14 个对象，中心单独聚焦，没有持续后台模拟，不把距离或连线密度解释为剧情强度。2026-11-10 初版的 120 步静态弹簧布局为历史实现。

人物／事件、地点、势力、物品／其他、伏笔分别使用圆、方、六边形、菱形、三角形。点选、鼠标旋转、缩放按钮与完整名称列表继续可用。来源详情可核对固定历史稿中的同段逐字引文；跳到当前稿时重新核对章节修订和段落，并经过 App 的正文保存与未决请求门禁。

星图只读请求的超时回执、读取错误和刷新入口在星海、关系、矩阵、雷达四个视图中共同可见。超时后先查询原请求；读取结束只解除等待，作者显式刷新后建立新快照。

## 出场矩阵

新只读 `story.matrix`／`readAppearanceMatrix` 在同一事务中读取版本、总数和页数据，实体每页 12 个、章节每页 24 章，两方向独立翻页。后续页必须固定 `bookRevision` 和 `knowledgeRevision`；资料变化返回版本冲突，重新读取第一页。

| 状态 | 数据依据 |
| --- | --- |
| 登场行动／被提及 | 已采纳的事件，性质为作者设定、正文陈述或 AI 推断；实体为实际参与者或提及对象，且有该章正文来源 |
| 当前登记 | 事件标为当前、无候选冲突，来源修订与章节当前稿一致 |
| 已核对缺席 | 作者在事件表单读取整章、明确选择缺席实体并填写说明；核对绑定当前保存稿修订 |
| 登记有冲突 | 同一实体、同一章既有当前正向登记，又有当前整章缺席登记 |
| 旧稿／待复核 | 已采纳事件的来源或核对不再对应当前稿，或记录需要复核、存在候选冲突 |
| 未知 | 没有符合以上规则的登记；未索引不等于缺席 |

事件增加可选 `appearanceCheck`，保存章 ID、固定修订、非空缺席实体集合和核对说明。同一事件的参与者、提及对象与缺席实体不能重叠。新增或重做核对必须使用当前已保存稿；未改动的旧核对可保留，矩阵按旧稿显示。缺席不写入“提及”引用，也不生成任何人物认知；实体查询和记忆投影可以追溯这条核对。

表单读取另一章或新稿时，旧缺席名单和说明仍绑定原修订；须核对全文后明确确认沿用，或以新稿清空本次名单重新登记，才切换保存基线。新稿待确认期间暂停编辑名单和说明，避免把旧结论自动移到新稿；历史快照继续保留。

每格计数覆盖全部命中，每类最多附一个代表记录，代表记录数量不是命中总数。连续缺席提醒只计算**当前章节窗口末尾**连续有效的明确缺席；未知、冲突或正向登记中断计数。阈值为 1–24 章，默认 10，不推断窗口外或全书缺席。

## 伏笔雷达

新只读 `story.radar`／`listForeshadowRadar` 每页 20 条，同样固定作品和知识双版本。作者明确选择“核对到哪一章”，不把最后一个已建章节当作写作进度。列表可查未结束、到期及逾期、已结束或全部记录。

| 目标或状态 | 到期口径 |
| --- | --- |
| 已建章／固定段落 | 使用该章当前叙述位置；位置相同为到期，已越过为逾期 |
| 已建卷 | 所选进度进入该卷即提醒，进入后卷才逾期；不虚构逾期章数 |
| 未建卷章 | 可明确填写 1–200000 的 `targetNumber`，与当前卷章序号比较；不能同时绑定已有卷章 |
| 场景 | 使用未归档场景的当前所属章；场景不存在、已归档或与同时登记的章节不符时待定位 |
| 纯文字范围／无进度／失效目标 | 范围待定位，不解析“卷末”等文字猜测期限 |
| 尚未采纳、过时或候选冲突 | 待作者复核 |
| 已回收／已放弃 | 已经结束，保留历程与来源 |

计划与实际回收分别保存。新确认回收或更换回收位置时，必须同时有该章、该修订、该段落的已保存或本次追加逐字引文；原有历史已回收记录在未更换位置时保持兼容，不补造证据。雷达可进入指定记录编辑回收计划、查看里程碑和固定原稿。

写作右栏与作者创作的 AI 面板显示本章到期／逾期提醒，首屏最多列三条，完整范围进入雷达。提醒在换章或显式刷新时读取，正文自动保存不反复扫描；作品版本改变后提示结果来自上次核对。

## 伏笔进入 AI 上下文

作者明确选择后才附加伏笔，仍须保存发送预览、核对实际消息并确认发送。资源保留精确记录 ID 和最新不可变知识修订；服务端重读最新记录及该修订，字段或修订改变就要求重选。未采纳、过时、候选冲突及已结束记录不可使用。

伏笔资源标为 `role=plan`，保留性质、阶段和计划范围，明确计划不等于已经发生或人物知情。最多附最后八项里程碑，每项说明最多 1000 字符，固定来源引文保留；省略和节选明确标注。与场景、笔记、方法等合计最多八项，继续遵守单资源和发送预算限制。人物视角不由该入口附加作者全知计划。
