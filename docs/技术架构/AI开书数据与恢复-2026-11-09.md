# AI 开书数据与恢复

编写日期：2026-11-09。本说明对应[AI 原生重构方案](../产品文档/小说工作台AI原生重构方案-2026-11-09.md)的 M1 源码。这里只记录实现与静态检查边界，运行和验收状态见[开发进度](../开发进度/开发进度-2026-11-06.md)。

## 入口与流程

首页和书架的创建入口进入全画布故事孵化页，保留手工建书。先填写脑洞、题材、篇幅和叙事模板；可以先保存草稿，再配置模型。保存时用固定客户端 UUID 建立 `kickstarting` 作品，重复提交先查已有资产或登记孤立作品，不覆盖已有目录。

预览先保存故事种子，再建立独立的 `prepared` 尝试。它固定连接、提示版本、实际消息、输入指纹、作品和知识版本。作者确认发送后才进入 `running` 并请求兼容 Chat Completions 的流式接口。更改种子、连接或配置后需要重新预览。token 输入量为本机粗估，用量只显示服务方返回的数值。

完成后展示书名、故事核、主角和首章冲突；人物、规则、简介及完整三层大纲渐进展开。最近 100 次尝试可切换读取，历史记录仍保存在本书数据库。分区生成保留其余候选身份；人物职责须保留，修改人物或规则默认取消旧章纲选用。未选入的引用人物会阻止采用该章纲；取消被引用人物时，界面同步取消章纲选用。

M1 采用粒度是一个书名、逐个人物、逐条规则和整份大纲。候选内容编辑、逐章大纲选择、后续滚动补纲和修纲差异属于后续阶段；M1 通过分区重生成调整内容。

## 格式与数据归属

| 对象 | 位置与边界 |
| --- | --- |
| 工作区连接 | `studio.sqlite` v3 的 `studio_ai_connections`；最多 20 个，最多一个默认连接，配置按版本保存 |
| 会话密钥 | 桌面主进程内存，按书库、连接 ID 和基础地址隔离；不进入服务请求、数据库、预览、日志或恢复副本 |
| 草稿与书级资料 | `book.sqlite` v15；`lifecycle`、`seed_json`、`logline`、`master_outline_json` |
| 初版大纲 | 卷目标、冲突、高潮；章目标、冲突、悬念、可空紧张度、结构化节拍及待复核标记 |
| 生成尝试 | 本书 `generation_runs`；实际输入、连接快照、原始输出、选择、状态和版本 |
| 采用回执 | 本书 `generation_adoptions`；候选与目标实体／修订映射、首章身份，禁止更新和删除 |
| 未确认终态 | 书库 `pending-generation-results/` 分卷；独立于原有正文与向量结果留存目录 |

旧 studio v2 仍可打开，空连接读取不改结构。首次保存工作区连接时，先将目录库备份至 `studio-backups/v2-<UUID>/studio.sqlite`，核对备份身份和完整性后，在事务中追加配置表并升至 v3。界面在保存前说明这项变化。失败残件保留，不能直接用未完成备份替换原库。

新建和导入作品使用 v15；旧作品继续按既有格式读取，只有明确的备份升级入口追加 v15。新建和升级共同使用 `GENERATION_BOOK_UPGRADE`，恢复验证分别使用历史基础结构、完整 v14 和 v15 结构，避免新字段污染旧格式白名单。手工作品紧张度缺失保留 `NULL`，不伪造模型评分。

## 采用事务与恢复

采用前再次核对作品、知识和提案版本，限定未归档的孵化作品；已有卷章时拒绝开书。一个本书事务写入书名与简介、所选人物和规则、首卷与开篇章节、正文初版、outbox、候选状态及采用回执。人物与规则记录作者的明确采用，并关联原候选身份。

相同尝试再次采用时先读取回执，不重复创建卷章。目录缓存在本书提交后刷新，失败不撤销本书已提交结果。正文协作保存本次生成使用的连接配置，会话密钥仍只由主进程按工作区解析。若草稿已有相同连接身份则明确拒绝覆盖，保留原配置与提案。

模型请求前检查结果目录可写性及磁盘余量。流接收限制为 180 秒、4 MiB 响应、128 KiB 事件和 60,000 字符输出；按收到的有效文本定期保存进度。错误、截断与中止不自动重发，原始输出保留。完整终态先独占写入并同步到留存分卷，再提交本地结束记录；重开时只补存原结果，不重新访问模型。尚未写入进度的尾部仍可能随异常退出丢失。

读取会尝试补存终态；留存故障仍允许查看已保存内容，并显示待处理原因。没有活动会话且没有待补存冲突时，将遗留 `running` 标为中断。未知写入按原请求 ID 查询回执；原请求未确认时不创建新的重复写入。不能核对时可复制当前草稿与已读内容后进入恢复；完整未落库结果仍由主进程的另存流程保护。副本不含密钥，重连需要重新填写。

单书恢复包接受 v15，校验草稿种子、总纲与节拍、输入指纹、结构化提案和原始输出、父尝试顺序、采用目标及实际修订。仍在运行的生成不能导出。恢复包包含本书已经保存的生成记录与采用回执；工作区连接池、会话密钥、目录库备份及待提交终态目录不属于单书包。
