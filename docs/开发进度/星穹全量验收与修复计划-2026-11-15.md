## 执行边界与集中授权

根 [AGENTS.md](../../AGENTS.md) 要求对本机启动、测试、类型检查和构建取得明确授权，一般性的实现、修复或验证要求不代替这些授权。下表为开始时集中申请并经用户“允许”的执行范围，现已按相应边界执行；实际结果以总报告为准：

| 操作 | 拟执行方式与范围 | 影响与保护 |
| --- | --- | --- |
| 静态检查 | `node scripts/check-renderer-static.mjs`、针对性源码比对、`git diff --check`、文档链接核对 | 不启动项目、不调用业务函数；不能替代运行验收 |
| 类型检查 | `npm run typecheck`，覆盖 Node 与 Web 两个配置 | 顺序执行；不通过则定位并修复，不放宽类型约束掩盖问题 |
| 生产构建 | `npm run build` | 更新本仓库 `out`；配置为 `emptyOutDir: false`，保留已有资源与验收现场 |
| 隔离桌面与业务验收 | 启动本轮生产构建，使用本仓库 `out` 下新的唯一验收目录和独立用户配置、书库、导入及导出文件 | 不打开或修改真实书库，不关闭或重启用户正在使用的实例；先验证隔离生效再写入 |
| 备份、升级、恢复及错误分支 | 仅在上述合成验收数据及本轮创建的独立副本执行；通过受控故障检查失败行为 | 原件、备份、失败现场保留；不填满真实磁盘、不破坏真实文件、不修改系统设置 |
| 文本与图片模型联调 | 仅使用用户先前指定的连接和合成输入；本轮上限为文本 30 次、图片 2 次，顺序执行 | 不输出或提交密钥；不发送真实书稿，不自动重发未知结果，不充值或切换未授权提供方 |
| 最终桌面产物核对 | 核对实际入口目标、最终构建标记、资源引用和隔离窗口中的版本，再通过正常关闭握手退出验收实例 | 不改快捷方式或安装目录，不强制结束现用实例；需改这些对象时另列精确目标与影响 |

不安装依赖、不创建或改写单元测试、不删除验收目录或旧产物。必要的联调检查采用实际桌面界面与 IPC／存储链路；不得用直接改数据库的方式伪造界面通过。运行入口或自动化工具不可用时，保留具体失败证据，不以模拟页面冒充真实客户端。

本次集中确认涵盖上表非静态操作及修复后的必要重跑。涉及真实数据写入、安装包部署、快捷方式变更、系统设置和运行中服务的操作仍不在该范围内。
