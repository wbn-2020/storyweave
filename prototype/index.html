「织章」是一份离线可用的创作工作台交互原型。先体验 UI 与流程，再决定产品如何生长。
  1. 从画布出发点选事件、人物或伏笔，查看它与章节的关系。
  2. 保留自己的声音正文可直接编辑。示例建议可逐句插入，也可安全撤销。
  3. 让修改经过你在 F03 来源设定中准备修改，预览影响后明确确认。
  4. 把故事带走本地留版本，下载 Markdown 正文或 JSON 设计资产。
不连接真实模型，不上传内容，不收集账号或凭据。所有建议均为预置示例；本地保存不可用时，会明确提示会话模式。
