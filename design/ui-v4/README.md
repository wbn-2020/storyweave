# 织章 · 完整版 UI 交互原型 v4

日期：2026-11-04。依据 PRD v1.0，面向个人、本机或私有服务器使用。

用 Chrome 或 Edge 打开 [index.html](index.html)，不需要安装依赖或启动服务。主程序是同目录的 `app.js` 和 `styles.css`，一起保留即可离线打开。

## 建议浏览路线

1. **我的书架 → 继续写作**：打开《潮汐档案》的“仓库对证”。正文可直接编辑，场景与字数跟随页面内数据更新。
2. **本场记忆 → 查看来源**：分别看作者规则、人物此时状态、原文与伏笔计划；来源可以定位选中正文。手机从“本场记忆”打开抽屉。
3. **带记忆续写 → 开始模拟续写**：预览具体输入，播放固定的、故意含偏离的提议。
4. **逐项审阅**：处理影像能力、右手伤势、提前解释编号三处示例，再查看完整提议并采用到正文。
5. **待办与审阅 → 记忆候选**：正文采用后，新事件仍需作者单独确认。修订影响也有独立复核入口。
6. **知识星系 / 人物档案 / 伏笔追踪**：查看同一组故事对象如何关联，人物时点与计划回收如何表达。
7. **新建作品**：查看真实的原型空态，创建自己的场景与设定；不会把《潮汐档案》的正文带到新作品。

## 页面与操作

| 页面 | 原型中可操作的内容 |
|---|---|
| 我的书架 | 继续创作、作品切换、新建作品、文字迁入 |
| 正文创作 | 场景切换、纯文本编辑、字数、场景目标、专注、记忆抽屉、来源定位 |
| 故事大纲 | 章场视图、添加场景、调整所属章节、跳回正文 |
| 创作契约 | 修改作品名、一句话故事、类型、默认视角、文风和创作边界 |
| 知识星系 | 深度投影、拖动旋转、缩放、类型筛选、搜索、对象列表、关联聚焦、来源侧读 |
| 人物档案 | 人物搜索与创建、档案编辑、三个预置时点、状态与知情分栏 |
| 世界设定 | 规则、地点、物品切换；创建与修改作者设定；关联对象与原文 |
| 故事时间线 | 演示故事发生顺序 / 当前叙述顺序切换，场景与计划区分 |
| 伏笔追踪 | 新建计划、调整回收窗口、准确引文校验、作者确认实际回收 |
| 素材与笔记 | 新建与编辑笔记、导航后保留、明确转为作者设定 |
| 待办与审阅 | 续写偏离、稍后与重新处理、撤回决定、记忆候选采用/拒绝、修订来源复核 |
| 历史与检查点 | 本页操作记录、命名检查点、两稿比较、恢复前保留当前稿 |
| 工作台设置 | 字号、纸色、行距；导入导出；模型用途说明；异常状态入口 |

全局 `Ctrl K` / `Command K` 搜索当前作品的场景、知识和笔记。对话框支持 Escape，手机左上角打开导航。

## 视觉设计

沿用夜航外框、暖纸正文、浅铜主操作。书封与几何线条为本项目原创 HTML/CSS/SVG，不复制参考项目的界面素材。正文、笔记与证据引用使用纸面；知识与工具保留深色。

全书星系使用 **Canvas 2D 深度坐标投影**，初始有 14 个原创故事对象、260 个背景密度点与独立星尘。背景没有事实身份，不进入记忆。窄屏只突出选中对象及相关标签，完整对象仍在列表中；Canvas 不可用时切换列表。

## 明确边界

- **这是页面和交互原型。** 所有操作只存在当前页面的 JavaScript 内存中；刷新或关闭会还原。没有 localStorage 持久化、数据库、真实保存回执、身份系统或备份恢复服务。
- AI 续写、偏离发现、知情时点与记忆包是《潮汐档案》的预置演示，不能当作真实检索、自动抽取或长期一致性能力。只有“仓库对证”配置了固定续写旅程，其他场景支持手写。
- 草稿修改、源文摘录匹配、版本过期阻止采用、候选决定、章节移动、独立作品与导出在本页实际执行。记忆待复核只是演示标记，没有正式依赖图或增量重建。
- 新建伏笔是计划；记录实际回收会检查引文确实存在，是否回答问题由作者确认。没有模型自动判定语义回收。
- 时间线使用演示场景的预置发生顺序和可调整的叙述顺序。不是通用时间解析或复杂时态引擎。
- Markdown 下载是真实的当前作品读者稿；JSON 是原型状态快照，不是正式资产恢复包。文字导入使用粘贴纯文本，创建独立新作品，不支持 DOCX/PDF、自动切章或正式恢复。
- 异常入口展示界面处理方式，不注入真实网络或存储故障。完整产品仍须验证真实保存、长篇容量、模型质量、输入法、触屏手势、屏幕阅读器与长期写作体验。

原有 `prototype/`、`design/ui-v1/`、`ui-v2/`、`ui-v3/` 保留。本轮没有正式业务工程、依赖安装、凭据读取、数据库连接、提交、推送或部署。
