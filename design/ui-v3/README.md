# v3 · 长期记忆工作台设计预览

2026-11-04。入口：[preview.html](preview.html)。无需安装、联网或启动服务，可用浏览器直接打开。完整规格见 [PRD](../../docs/10-prd.md)、[记忆方案](../../docs/13-long-memory-system.md) 和 [UI 说明](../../docs/14-galaxy-ui-design.md)。

## 范围

三个主页面：创作、本场记忆与来源；全书星系；续写偏离审阅。支持页面切换、专注、来源侧读、输入范围示例、人物/伏笔筛选、对象搜索、列表、缩放/拖动和内存中的演示决定。

正文只读。没有真实编辑器、提取、检索、模型检查、数据库、保存、授权或费用功能。所有状态是原创设计样例；刷新重置演示决定。没有修改旧 v1/v2 或原型。

星系是 Canvas 2D 的深度坐标投影，包含 14 个故事对象和 180 个明确密度样本，背景星尘只是装饰；不是 WebGL 性能验收，不代表小说已提取。只有提供正文的规则可精确定位，其他对象说明没有正文证据。
